# Lithium-Ion Battery Health Monitoring and Predictive Analytics

## Project Overview

This project focuses on analysing lithium-ion battery performance, charging and discharging patterns, capacity degradation, temperature effects and battery health.

## Project Objectives

- Analyse battery charging and discharging behaviour.
- Monitor battery capacity over successive cycles.
- Estimate State of Health (SOH).
- Investigate temperature and usage effects.
- Develop predictive models for battery degradation.
- Visualise findings using Power BI.

## Tools and Technologies

- Python
- Pandas and NumPy
- SQL
- Statistical Analysis
- Machine Learning
- Power BI
